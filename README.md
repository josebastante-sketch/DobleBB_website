Maqueta estática (generada con Google Stitch y ajustada) para validar con DobleBB el nuevo enfoque de la web: soporte TI como servicio principal + "Top 3 del mes" de equipos recomendados, sin precios.

- Textos, cifras y testimonios marcados como ejemplo deben reemplazarse por datos reales antes de producción.
